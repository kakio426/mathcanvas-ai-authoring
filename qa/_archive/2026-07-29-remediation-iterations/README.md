이전 최종 후보를 보존합니다. 현재 품질 판정, 점수, 교사 전달에는 사용하지
않습니다.

- `probe-v21/`, `probe-v21-reload/`: 초기 패널 분리 프로브
- `probe-v211-zero-overlap/`: 초기 겹침 검사 보완본
- `probe-v212-final/`: 문구 겹침이 남았던 후보
- `probe-v220-clean-lanes/`: 목표 칸 문구 정리 단계
