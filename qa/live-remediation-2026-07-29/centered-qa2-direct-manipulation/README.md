# v2.4.1 직접 조작 QA

최종 네 캔버스를 변경하지 않기 위해 별도 새 QA 캔버스 `6WdElg`에서
Chrome 입력으로 아래를 실행했다.

1. `3/8` 띠를 첫째 비교 자리의 출발선에 맞춤
2. `3/5` 띠를 둘째 비교 자리의 출발선에 맞춤
3. `<` 기호를 관계 칸의 가운데에 놓음
4. 빈 입력칸을 활성화해
   `3/5 띠가 3/8 띠보다 더 길어요.`를 입력
5. 고정 안내를 눌러 선택 상태를 해제

실제 결과:

- 두 띠의 왼쪽·위쪽 경계가 목표 자리와 각각 `1px` 이내
- 놓은 기호의 관계 칸 중심 오차: 가로 `0.07421875px`,
  세로 `0.19921875px`
- 기호와 입력 문장 모두 자기 상자 안에 포함
- 마지막 선택 객체 0개

`metrics.json`은 실제 DOM rect 판정을, `after-manipulation.png`는 조작
완료 화면을 담는다.
