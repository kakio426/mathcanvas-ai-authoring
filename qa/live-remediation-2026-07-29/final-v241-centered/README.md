## 추가 화면 크기

같은 중심 정렬 검사를 `1630×1122`, `1280×800`, `1024×768`에서도
실행했다. 세 화면 모두 분수와 기호의 가로·세로 중심 오차는 `1px`
이하였다. 다만 120% 고정 배율에서는 `1280×800`과 `1024×768`의
MathCanvas 편집 도구막대가 활동 영역을 침범하므로 전체 화면 PASS로
기록하지 않는다. 이 결과는
`../final-v241-centered-multiview/metrics.json`에 보존한다.

`metrics.json`은 최종 네 캔버스의 실제 DOM rect와 중심 오차를,
`creation-and-validation.json`은 생성 URL·payload 해시·validator
결과를 담는다. `1.png`~`4.png`는 안내 오버레이가 사라진 최종 초기
편집 화면이다.
