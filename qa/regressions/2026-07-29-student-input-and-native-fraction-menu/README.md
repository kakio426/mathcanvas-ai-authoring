# 학생 입력·네이티브 분수 메뉴 회귀

등록일: 2026-07-29
대상: v2.3.0 캔버스 2/4 `feeTES`
현재 판정: FAIL

## 실패 1: 글쓰기 위치가 보이지 않음

근거: `failure-no-obvious-writing-field.png`

`3. 까닭을 써요` 오른쪽 문장은 미리보기에서 클릭하면 편집할 수 있지만,
첫 클릭 전에는 일반 안내문처럼 보인다. 학생이 입력 위치를 알아볼 수 있는
빈칸·연필·입력 라벨·배경 대비가 없다.

회귀 기준:

- 첫 클릭 전 3초 안에 학생이 입력 위치를 가리킬 수 있어야 한다.
- 지시문과 실제 입력 영역이 시각적으로 분리되어야 한다.
- 입력 영역 전체가 최소 42px 높이의 명확한 클릭 대상으로 보여야 한다.

## 실패 2: 분수식에 수식 메뉴를 쓰지 않음

근거: `failure-native-fraction-menu-ignored.png`

MathCanvas 아래 `수식` 메뉴에는 진분수와 대분수 템플릿이 있고, 왼쪽
`분수 모형`에는 `1`부터 `1/12`까지 띠·원 조각이 있다. 현재 드래그 띠는
`NO03FM` 네이티브 분수 모형을 사용했다. 그러나 화면의 `5/6`, `3/5`
카드는 수식 메뉴 대신 분자·선·분모를 독립 객체로 조립했다.

회귀 기준:

- 조작 모형은 네이티브 분수 모형을, 분수식은 수식 입력기를 우선한다.
- 독립 객체 조립은 네이티브 기능으로 해결할 수 없는 이유를 문서화한
  경우에만 허용한다.

## 화면 폭 회귀

`1710×895`, DPR 2에서 기본 60% 활동판 폭은 약 669px이었다. 확대,
전체 화면, 왼쪽 패널 접기를 직접 확인하지 않은 QA는 인정하지 않는다.
