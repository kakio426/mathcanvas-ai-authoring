## 확인된 실패

1. 분수 카드의 분모가 카드 아래로 빠져 비교판과 겹친다.
2. 주황 띠가 비교판 왼쪽 경계와 빨간 출발선을 덮는다.
3. 띠의 처음 자리와 옮길 자리가 분리되어 있지 않아 어디에서 어디로 끌어야 하는지 알기 어렵다.
4. `<`, `>`가 출발 상자 없이 떠 있어 옮길 물건이라는 단서가 약하다.
5. `알맞은 기호`, `비교한 까닭`이 각각의 조작 상자와 떨어져 있어 화면의 읽는 순서가 끊긴다.
6. 한 화면에서 띠 이동, 기호 선택, 문장 입력이 같은 위계로 펼쳐져 현재 행동이 하나로 보이지 않는다.

## 회귀 계약

- 분수 표기는 MathCanvas `math-latex` 한 객체에 맡기지 않는다. 분자, 가로선, 분모를 카드 안의 고정 객체로 조립한다.
- 띠 출발 상자와 빈 도착 자리를 서로 떨어진 두 영역으로 만든다.
- 움직이는 띠의 초기 경계는 도착 자리와 출발선에 닿지 않아야 한다.
- 기호는 각각 보이는 출발 카드 안에 놓고, 관계 기호 도착 칸과 분리한다.
- 설명 입력 라벨은 입력 상자 안의 머리말로 묶고, 별도 공중 라벨을 두지 않는다.
- 모든 고정 표면, 텍스트, 움직이는 객체, 도착 안내의 실제 경계 교차를 검사한다.
