# MathCanvas 수업 준비 macOS 앱

## 가장 쉬운 사용법

1. Finder에서 `응용 프로그램`을 엽니다.
2. `MathCanvas 수업 준비`를 더블클릭합니다.
3. 자동으로 열린 브라우저에서 수업을 준비합니다.
4. 화면을 다시 열거나 완전히 종료하려면 macOS 메뉴 막대의 `M`을 누릅니다.

로그인이 필요하면 수업 준비 화면의 `로그인 창 열기`를 누르고, MathCanvas 로그인을 마친 뒤 로그인 창을 닫습니다.

## 시험판 구조

- Electron이나 별도 WebView를 포함하지 않습니다.
- 약 408KB의 네이티브 실행기가 로컬 Node 서버를 백그라운드에서 실행합니다.
- 화면은 사용자의 기본 브라우저에 열립니다.
- 앱 종료 시 자식 로컬 서버도 함께 종료됩니다.
- Apple Silicon과 Intel Mac을 모두 지원하는 공용 바이너리입니다.

현재 시험판은 로컬 프로젝트 폴더와 설치된 Node.js 20 이상을 사용합니다. 다른 교사에게 배포할 최종 설치본에서는 Node 실행 환경과 빌드 산출물을 함께 묶고 개발 도구 의존성을 제거해야 합니다.

## 다시 만들고 설치하기

```bash
pnpm mathcanvas:app:macos:install
```

기존 앱이 있으면 바로 삭제하지 않고 macOS 휴지통에 시간표시 백업한 뒤 새 앱을 설치합니다.
