# 교육 설계와 문구 QA

## 교육과정 기준

- 공식 성취기준: `[6수01-07] 분모가 다른 분수의 크기를 비교하고 그 방법을 설명할 수 있다.`
- 학년군: 초등 5~6학년군
- 영역: 수와 연산
- 권장 학년: 5학년
- 보조 자료: `DECK6/korean-elementary-learning-map` 커밋 `3ef0563084aa2a9baaa47da2c1ec0ebf5d7edc5c`

교육부 원문 PDF 31쪽에서 코드와 목표를 대조했습니다. 보조 학습 맵의 고정 커밋은 같은 코드를 상위 단원 `분수의 덧셈과 뺄셈` 아래에 둡니다. 공식 목표는 교육부 원문을 기준으로 삼습니다.

## 첫 활동의 수학 행동

1. 학생이 두 분수 띠를 같은 출발선으로 옮깁니다.
2. 같은 전체 길이에서 색칠된 길이를 눈으로 비교합니다.
3. `<` 또는 `>` 기호를 관계 칸에 놓습니다.
4. 비교한 까닭을 한 줄로 씁니다.

단순히 정답 기호만 고르는 활동이 아닙니다. 학생이 같은 전체와 같은 출발점이라는 비교 조건을 직접 만들고, 띠의 길이로 관계를 판단한 뒤 그 까닭을 글로 남깁니다.

두 띠의 길이 차이는 전체의 8% 이상이어야 합니다. 쉬움은 28~56%, 보통은 15~27%, 어려움은 8~14.5%로 구성합니다. 생성기와 생성 직전 validator가 각각 검사합니다. 어려워질수록 분모가 커지고 띠 길이 차이가 줄어듭니다.

교사가 추천안을 확인할 때 각 문제의 비교식, 통분식, 분수 띠 설명을 담은 정답지도 함께 보여 줍니다. 예를 들어 `5/6=25/30`, `3/5=18/30`을 띠 길이와 연결합니다. 이 템플릿은 분수 띠로 크기를 비교하는 개념 형성 활동입니다. 성취기준 전체를 확인하려면 학생이 비교 방법을 말하거나 쓰는 후속 확인이 필요합니다. MathCanvas가 제공하지 않는 자동 채점이나 오답 피드백을 이 도구가 있는 것처럼 만들지는 않습니다.

## Humanizer 학생 문구 QA

검사 대상:

- `두 띠를 출발선에 맞춰 비교해 보세요.`
- `출발선`
- `알맞은 기호`
- `비교한 까닭`
- `띠의 길이를 보고 한 줄로 써 보세요.`
- `같은 전체에서 두 띠를 같은 출발선에 놓으면 5/6 띠가 더 깁니다.`
- `더 큰 분수는 5/6입니다.`

판정:

- 한 문장에 행동 하나
- 초등학생이 소리 내어 읽기 쉬움
- `메커니즘`, `오브젝트`, `게이트`, `payload` 같은 제작자 말 없음
- 번역투와 과도한 명사 나열 없음
- 같은 뜻 반복 없음

결과: 통과

Humanizer 자연도: A. 문구가 짧아 통계적 패턴 분석에는 한계가 있지만, 번역투·어른 중심 한자어·불필요한 쉼표·명사 나열이 없습니다. 수치·고유명사·수학적 관계와 학생 행동을 그대로 보존했습니다.
