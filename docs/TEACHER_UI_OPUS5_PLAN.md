# 교사용 수업 준비 화면 구현 결정

2026-08-01 Claude Opus 5 CLI 검토를 바탕으로 다음 방향을 채택했다.

- 제품 형태: 외부에 공개하지 않는 `127.0.0.1` 전용 웹 화면
- 사용자 흐름: 연결 확인 → 수업 설명과 세 가지 선택 → 학습 흐름 확인 → 명시적 승인 → 새 활동 생성
- 서비스 구조: MCP와 UI가 `@mathcanvas/authoring-runtime`을 함께 사용
- 승인 경계: 추천안의 내부 ID와 해시는 서버 메모리에만 두고, 미리보기를 연 세션에 발급한 일회용 승인 토큰이 있어야 생성
- 교육 원칙: `수학적 선택 → 생각의 어긋남 → 불변 관계로 확인 → 설명하고 수정`을 미리보기의 핵심 정보로 표시
- 시각 방향: MathCanvas의 청백색 작업 공간·파란 핵심 행동·도구 범주색을 이어받되, 교사가 학습 흐름을 빠르게 검토할 수 있는 활동 카드로 구성
- 비목표: 좌표 편집기, 기존 프로젝트 수정, 활동 이력·계정·클라우드 배포

초기 수직 슬라이스는 현재 서비스가 반환하는 검증된 추천 활동 한 가지를 깊이 있게 확인하고 생성하는 흐름에 집중한다. 여러 추천안 비교와 자연어 수정 루프는 실제 교사 사용성 확인 뒤 확장한다.
